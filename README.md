# War Thunder Hacks

Astro + TypeScript foundation for an SEO-first War Thunder cheats site.

```sh
cd war-thunder-cheats
npm run dev
npm run check
npm run build
```

Replace `src/data/site.ts` (`domain`, `url`) before launch. Commercial CTAs use `PURCHASE_URL` in `src/data/cta.ts`. Do not scatter the purchase URL through components.
